# TorchLauncher 시작하기

서버 운영자는 **TorchLauncher Studio**에서 서버에 맞는 런처를 만들고, 플레이어는 전달받은 런처로 서버에 접속할 수 있습니다. 이 안내 문서는 제품이 배포되면 구체적인 설치 과정을 추가할 수 있도록 마련한 기본 문서입니다.

## 서버 운영자

1. 다운로드 페이지에서 운영체제에 맞는 **TorchLauncher Studio**를 받습니다.
2. 새 프로젝트를 만들고 서버 이름과 브랜딩을 설정합니다.
3. Minecraft 버전과 Fabric 또는 NeoForge 로더, 배포할 모드를 구성합니다.
4. 프로젝트를 저장하고 플레이어에게 전달할 런처를 내보냅니다.

자세한 배포 설정과 서명 안내는 Studio 배포가 시작되면 추가할 예정입니다.

## 플레이어

1. 서버 운영자가 제공한 TorchLauncher를 실행합니다.
2. Microsoft 계정으로 로그인한 뒤 설치가 끝나면 **플레이**를 누릅니다.
3. 문제가 생기면 서버 운영자에게 전달받은 서버 안내와 런처 로그를 확인합니다.
