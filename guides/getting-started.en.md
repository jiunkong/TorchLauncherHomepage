# Getting started with TorchLauncher

Server owners create a launcher for their server in **TorchLauncher Studio**. Players use that launcher to join. This starter guide is ready to grow with the product as downloads and detailed setup steps become available.

## For server owners

1. Download **TorchLauncher Studio** for your operating system.
2. Create a project and set your server name and branding.
3. Configure a Minecraft version, a Fabric or NeoForge loader, and the mods to distribute.
4. Save the project and export a launcher to share with your players.

More details about deployment settings and signing will be added as Studio releases become available.

## For players

1. Open the TorchLauncher provided by your server owner.
2. Sign in with your Microsoft account and select **Play** after setup finishes.
3. If something goes wrong, check the server instructions and launcher logs, or contact your server owner.
